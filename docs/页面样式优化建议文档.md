# Genie AI Toolbox 界面优化规范文档
> 本文档为 Genie AI Toolbox App 的 UI/UX 优化规范，包含设计系统、各页面细节优化、交互与动效、工程化实现指南，可直接交付给 Codex 进行开发落地。

---

## 一、项目背景与优化目标
### 1.1 项目信息
- 应用名称：Genie AI Toolbox
- 包名：`com.genieai.toolbox`
- 平台：移动端（iOS/Android 双端）
- 当前问题：界面存在典型的「AI 设计通病」，视觉层级扁平、质感薄弱、品牌识别弱、交互体验单一，缺乏专业产品的统一设计语言。

### 1.2 核心优化目标
1.  **建立统一的设计系统**：实现色彩、间距、字体、图标、圆角、阴影的全链路规范，保证界面一致性。
2.  **强化视觉层级与质感**：解决当前界面“千篇一律”的扁平问题，通过色彩、阴影、动效打造专业的空间层次感。
3.  **提升用户体验**：优化信息呈现逻辑、交互反馈与操作路径，降低用户使用成本。
4.  **强化品牌识别**：提炼专属品牌视觉符号，打造 Genie AI Toolbox 的专属产品气质。

## 二、基础设计系统规范（核心，必须严格执行）
### 2.1 色彩系统

| 用途 | 色值（HEX） | 场景说明 |
| :--- | :--- | :--- |

#### 2.1.2 中性色系统（灰度）
| 色值（HEX） | 用途说明 |

| 错误/危险色 | `#EF4444` | 删除操作、错误提示、危险行为 |

### 2.2 间距与栅格系统
采用 **8px 栅格系统**，所有边距、内边距、图标尺寸、组件间距必须为 8 的倍数，保证界面的呼吸感与一致性。
| 间距值 | 用途说明 |
| :--- | :--- |
| `4px` | 极小间距（图标与文字间距、组件内微间距） |
| `8px` | 基础间距（卡片内边距、列表项上下间距） |
| `16px` | 模块间距（卡片与卡片间距、页面边距） |
| `24px` | 大模块间距（页面头部与内容间距、板块分隔） |
| `32px` | 超大间距（页面顶部安全区、特殊模块间距） |

---

### 2.3 圆角规范
| 组件类型 | 圆角值 | 场景说明 |
| :--- | :--- | :--- |
| 小按钮/标签 | `8px` | 胶囊按钮、标签、输入框、小操作按钮 |
| 卡片/容器 | `12px` | 功能卡片、列表项、聊天气泡、弹窗 |
| 大容器/特殊模块 | `16px` | 发现页Banner、个人页头部背景、弹窗大容器 |
| 圆形 | `9999px` | 头像、圆形图标、胶囊按钮（通栏） |

---

### 2.4 阴影规范
| 层级 | 阴影参数 | 用途说明 |
| :--- | :--- | :--- |
| 基础卡片阴影 | `0 1px 3px rgba(0, 0, 0, 0.05), 0 1px 2px rgba(0, 0, 0, 0.1)` | 普通功能卡片、列表项、轻量容器 |
| 高亮/悬浮阴影 | `0 4px 6px -1px rgba(0, 0, 0, 0.1), 0 2px 4px -1px rgba(0, 0, 0, 0.06)` | 按钮点击态、卡片hover态、特殊模块 |
| 弹窗/浮层阴影 | `0 10px 15px -3px rgba(0, 0, 0, 0.1), 0 4px 6px -2px rgba(0, 0, 0, 0.05)` | 弹窗、浮层、底部操作栏 |

---

### 2.5 字体与文字层级
采用无衬线字体，优先使用系统无衬线字体（iOS 用 SF Pro，Android 用 Roboto，兜底用思源黑体），严格区分文字层级。
| 层级 | 字号（移动端） | 字重 | 行高 | 用途说明 |
| :--- | :--- | :--- | :--- | :--- |
| 大标题 | `20px` | 700（Bold） | `28px` | 页面标题、Banner主标题、模块大标题 |
| 标题 | `17px` | 600（Semibold） | `24px` | 卡片标题、列表项主文案、聊天消息主文案 |
| 正文 | `15px` | 400（Regular） | `22px` | 普通文案、聊天回复内容、设置项文案 |
| 辅助文字 | `13px` | 400（Regular） | `18px` | 说明文字、占位符、次要信息、标签文字 |
| 极小文字 | `11px` | 400（Regular） | `16px` | 算力说明、底部小字、版权信息 |

---

### 2.6 图标规范
1.  **图标风格**：统一使用线性/面性二选一风格，推荐使用面性图标，保持品牌的科技感与现代感，禁止混用不同风格的图标。
2.  **图标尺寸**：
    - 导航栏图标：`24x24px`
    - 卡片/列表项图标：`20x20px`
    - 按钮/小图标：`16x16px`
3.  **图标颜色**：主图标用品牌主色，次要图标用 `#6B7280`，危险图标用错误色 `#EF4444`。

## 三、分页面详细优化方案
### 3.1 对话页（AI Chat 页面）
#### 3.1.1 页面结构优化
1.  **顶部导航栏**
    - 布局：左侧汉堡菜单按钮（`24x24px`，线性图标），中间标题区，右侧算力胶囊按钮。
    - 标题区优化：
      - 主标题：`AI Chat`，字号 `17px`，字重 `600`，颜色 `#111827`。
      - 副标题：`Doubao`，字号 `13px`，颜色 `#6B7280`，放在主标题下方，居中对齐。
    - 算力胶囊按钮：
      - 样式：背景 `#E0E7FF`，圆角 `9999px`，内边距 `8px 12px`。
      - 内容：闪电图标（`16x16px`，`#4F46E5`） + 文字 `180`（字号 `15px`，字重 `600`，`#4F46E5`）。

2.  **聊天气泡优化**
    - 用户气泡（右侧）：
      - 背景：品牌主色 `#4F46E5`，圆角 `12px`，仅左下角保留 4px 对话尖角，其余圆角 `12px`。
      - 文字：字号 `15px`，颜色 `#FFFFFF`，行高 `22px`，内边距 `12px 16px`，最大宽度为屏幕宽度的 75%。
    - AI 气泡（左侧）：
      - 背景：`#F3F4F6`，圆角 `12px`，仅右上角保留 4px 对话尖角，其余圆角 `12px`。
      - 文字：字号 `15px`，颜色 `#374151`，行高 `22px`，内边距 `12px 16px`，最大宽度为屏幕宽度的 75%。
      - AI 标识：气泡左侧增加 `AI` 圆形标识（`32x32px`，背景 `#4F46E5`，文字 `AI` 白色，字号 `13px`，字重 `600`），与气泡顶部对齐。

3.  **输入框区域优化**
    - 布局：输入框 + 附件按钮 + 发送按钮，底部增加安全区边距。
    - 输入框：
      - 背景：`#FFFFFF`，边框 `1px solid #D1D5DB`，圆角 `12px`，内边距 `12px 16px`。
      - 占位符文字：字号 `15px`，颜色 `#6B7280`，内容 `输入消息...`。
      - 聚焦态：边框颜色变为 `#4F46E5`，背景变为 `#FAFAFA`。
    - 附件按钮：
      - 样式：`24x24px` 线性图标（`+`），颜色 `#6B7280`，点击态变为 `#4F46E5`。
    - 发送按钮：
      - 样式：背景 `#4F46E5`，圆角 `8px`，内边距 `10px 16px`，图标为白色箭头（`16x16px`）。
      - 禁用态：背景变为 `#D1D5DB`，图标颜色 `#FFFFFF` 透明度 0.7。

## 四、交互与动效规范（提升专业质感的关键）
### 4.1 基础交互反馈
1.  **按钮反馈**：所有可点击按钮/卡片，点击时增加 `scale(0.98)` 缩放动画，持续 `100ms`，恢复时 `scale(1)`，增加轻微的透明度变化。
2.  **输入框反馈**：聚焦时边框从 `#D1D5DB` 平滑过渡到 `#4F46E5`，持续 `200ms`。
3.  **列表项反馈**：点击列表项时，背景色短暂变为 `#F3F4F6`，持续 `100ms` 后恢复。

### 4.2 页面转场动效
1.  页面切换使用系统标准的侧滑/淡入淡出动画，持续 `300ms`，禁止生硬的跳转。
2.  弹窗/浮层使用淡入+从底部滑入的动画，持续 `300ms`，退出时反向动画。

### 4.3 特殊场景动效
1.  聊天气泡加载时，使用淡入+从侧方滑入的动画，持续 `200ms`，AI 回复可增加打字机效果。
2.  下拉刷新/上拉加载时，使用与品牌主色匹配的加载动画，禁止使用默认的系统加载样式。

## 五、工程化实现指南（Codex 开发参考）
### 5.1 组件化实现建议
1.  封装通用基础组件：
    - `BaseButton`：支持主色/次色/危险色、圆角、尺寸、禁用态的通用按钮组件。
    - `BaseCard`：支持圆角、阴影、内边距的通用卡片组件。
    - `BaseInput`：支持聚焦态、占位符、边框的通用输入框组件。
    - `BaseListItem`：支持图标、文字、右侧箭头的通用列表项组件。
2.  统一管理设计系统变量：
    - 定义全局 CSS 变量（或 uni-app 主题变量），管理所有颜色、间距、圆角、阴影值，避免硬编码。
    - 示例（CSS）：
    ```css
    :root {
      --color-primary: #4F46E5;
      --color-primary-light: #E0E7FF;
      --color-text-primary: #111827;
      --spacing-8: 8px;
      --border-radius-12: 12px;
      --shadow-card: 0 1px 3px rgba(0, 0, 0, 0.05), 0 1px 2px rgba(0, 0, 0, 0.1);
    }
    ```

### 5.2 响应式适配要求
1.  所有页面需适配不同尺寸的移动端屏幕，使用弹性布局（flex/grid）+ 相对单位（如 rpx、vw），避免固定像素值导致的适配问题。
2.  底部导航栏需适配 iOS/Android 的安全区，避免内容被系统栏遮挡。

## 六、验收标准
1.  所有页面的色彩、间距、圆角、阴影、字体严格符合本规范，无违反设计系统的元素。
2.  所有可交互元素均有明确的反馈动效，无生硬跳转或无反馈的操作。
3.  不同屏幕尺寸下布局正常，无元素溢出、遮挡或错位问题。
4.  界面整体视觉层级清晰，品牌识别明确，无“AI 设计”的扁平感。
