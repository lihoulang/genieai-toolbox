部署建议

如果你准备使用 GitHub Pages，建议直接发布当前 `docs/` 目录。发布完成后，页面链接通常会是：

  • `https://你的用户名.github.io/仓库名/privacy.html`
  • `https://你的用户名.github.io/仓库名/account-deletion.html`
  • `https://你的用户名.github.io/仓库名/support.html`
发布到 Play Console 前，请把 App 内配置的 `PRIVACY_POLICY_URL`、`ACCOUNT_DELETION_URL`、`SUPPORT_URL` 改成最终的 GitHub Pages HTTPS 链接。
