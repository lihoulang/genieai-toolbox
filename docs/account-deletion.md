# Account Deletion

Last updated: 2026-05-17

Users can delete their account from the in-app profile page by tapping `删除账号`.

Users can also request account deletion from the public web page by emailing:

- `819317636@qq.com`

Recommended email subject:

- `Genie AI Toolbox Account Deletion`

The deletion request should include:

- app username
- user ID, if visible
- a statement that the user wants to delete the Genie AI Toolbox account
- optional deletion reason or additional context
- confirmation that the user understands account deletion is permanent

Deletion currently removes:

- account profile data
- stored conversations and messages
- balance logs
- AI moderation reports
- active login sessions

Deletion is immediate and cannot be undone.

Web email deletion requests are usually processed within 7 business days. If payment reconciliation, fraud prevention, legal retention, or manual account verification is required, processing may take longer and the user will be told why.

If future versions retain any data for legal, audit, fraud prevention, or payment reasons, this page and the privacy policy must describe what is retained, why it is retained, and how long it is retained.

This repository copy is the source version of the deletion policy. Before submitting to Google Play, publish the final matching document at a public HTTPS URL and use that same URL in Play Console support or account deletion fields.

Suggested public URL:

- `https://lihoulang.github.io/genieai-toolbox/account-deletion.html`
